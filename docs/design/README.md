# Design notes and build plans

Before building, I wrote a design spec (`specs/`) and then step-by-step build plans (`plans/`).
I work with AI coding tools, and these documents are how I keep that work on track: the spec
sets the rules, each plan breaks the work into small testable steps, and I review each step
before it ships.

The "For agentic workers" note at the top of each plan is an instruction to the AI coding
assistant. I left the documents as they were used, so they show the real process.
